移动端 TBR 架构

移动 GPU 与桌面 GPU 是两种架构哲学。本文深入基于瓦片的渲染（TBR/TBDR），解释它为何是移动端性能的地基。

引言：移动 GPU 的核心约束是带宽与功耗

移动 SoC 的 GPU 与 CPU 共享同一块系统内存，内存带宽远小于桌面独显，且访问外部内存极其耗电（发热、降频的主因）。所以移动 GPU 的设计目标是：尽量少访问外部内存。TBR/TBDR 正是为此而生。
